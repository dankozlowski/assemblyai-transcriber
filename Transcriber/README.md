# Transcriber (Xcode project)

The xcodegen-managed Xcode project for Transcriber, a native macOS menu bar app that
captures system audio and microphone input, streams them to AssemblyAI for real-time
transcription with speaker diarization, and saves speaker-attributed transcripts to Obsidian.

This file covers building, testing, and regenerating the project only. For features,
first-time setup, usage, architecture, the AssemblyAI WebSocket protocol, cost, and
troubleshooting, see the [root README](../README.md).

## Layout

```
Transcriber/
├── project.yml                    # xcodegen project definition — the source of truth
├── Transcriber.xcodeproj/         # generated by xcodegen — do not edit by hand
├── Transcriber/
│   ├── TranscriberApp.swift       # @main — menu bar and window scenes
│   ├── Info.plist
│   ├── Transcriber.entitlements
│   ├── Models/                    # SessionConfig, TranscriptEntry
│   ├── Services/                  # audio capture, mixing, transcription, persistence
│   ├── ViewModels/                # TranscriptViewModel — orchestrates the services
│   └── Views/                     # PopoverView, TranscriptWindowView, SettingsView
└── TranscriberTests/              # unit tests
```

Edit `project.yml`, not `Transcriber.xcodeproj`. Any change made directly to the
generated project is lost on the next regeneration.

## Regenerate the project

```bash
xcodegen generate
```

Run this after adding or removing source files, or after editing `project.yml`.

Required on a fresh clone: the `Transcriber` scheme lives in `xcuserdata/`, which is
gitignored, so `-scheme Transcriber` will not resolve until you generate the project
at least once. Install xcodegen with `brew install xcodegen` if you do not have it.

## Build

```bash
xcodebuild -project Transcriber.xcodeproj -scheme Transcriber -configuration Debug build
```

Launch the built app:

```bash
open $(xcodebuild -project Transcriber.xcodeproj -scheme Transcriber \
  -configuration Debug -showBuildSettings 2>/dev/null \
  | grep ' BUILT_PRODUCTS_DIR' | awk '{print $3}')/Transcriber.app
```

## Test

```bash
xcodebuild test -project Transcriber.xcodeproj -scheme Transcriber -configuration Debug
```

15 tests:

| File | Tests | Covers |
|------|-------|--------|
| `MixingBufferTests` | 4 | drain threshold, overflow clamping, single-source operation |
| `TranscriptionServiceTests` | 5 | JSON parsing for Begin, Turn, Termination, and error events |
| `SessionConfigTests` | 3 | default values, slug generation, empty name handling |
| `TranscriptEntryTests` | 3 | final and partial entries, markdown formatting |

## Project settings that matter

| Setting | Value | Why it matters |
|---------|-------|----------------|
| Deployment target | macOS 14.0 | `SCContentSharingPicker`, used to pick the display to capture, is macOS 14+ |
| Swift version | 5.10 | |
| `LSUIElement` | `true` | No dock icon — the app lives in the menu bar |
| Bundle identifier | `com.dankozlowski.Transcriber` | |
| `CODE_SIGN_IDENTITY` | `Transcriber Dev` | A stable signing identity is what stops macOS from re-prompting for Screen Recording permission on every rebuild. Certificate setup is in the [root README](../README.md). Rename it here if your certificate is named differently. |
